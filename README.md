# Distracted Driver Analytics Pipeline

## Overview

This project explores distracted driving behaviours using a modern driver behaviour image dataset.

Rather than training a computer vision model, the focus is on building an end-to-end analytics pipeline using:

- Python
- Databricks
- Delta Lake
- SQL
- Power BI

## Architecture

Raw Images
→ Metadata Extraction (Python)
→ Bronze Layer (Databricks)
→ Silver Layer
→ Gold Layer
→ Power BI Dashboard

## Dataset

Multi-Class Driver Behavior Image Dataset

Behaviour categories:

- Safe Driving
- Talking on Phone
- Texting on Phone
- Turning
- Other Activities
